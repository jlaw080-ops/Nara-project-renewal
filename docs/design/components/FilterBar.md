# FilterBar

조회 조건 패널. 원본에서 화면 절반을 차지하던 조건 줄을 두 줄로 줄였다.

- 1줄: 수요기관(펼침 버튼 "N곳 선택 ▾" → 검색·체크 목록이 뜨는 `.picker__pop`), 이름 검색(남는 폭 차지), 공고일 기간, 오른쪽 끝에 조건 지우기 · **조회**.
- 2줄: 진행현황·관심기관만·실행부서 검토 필요·숨긴 사업을 켜고 끄는 칩(`.chip`, `aria-pressed`). 원본의 여러 줄 select(Ctrl 클릭)보다 쉽다.
- 패널(`.panel`) 안에 두고 표와 한 화면에 보이게 한다.
