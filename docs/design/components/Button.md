# Button

세 단계 위계: **주 버튼**(`.btn`, 파랑) · **보조 버튼**(`.btn--secondary`, 흰 바탕 테두리) · **조용한 버튼**(`.btn--quiet`, 글자만).

- 한 구역에 주 버튼은 하나: 조회, 저장, 로그인. 나머지(선택 해제, 이 사업 다시 조회, 엑셀로 받기)는 보조, 취소·조건 지우기는 조용한 버튼.
- 크기: 기본 `control-md` 40px, 도구줄·표 위는 `.btn--sm`(`control-sm` 32px).
- 모서리 `radius-md`, 글자 `body-strong`. 비활성은 투명도 0.5.
- 글자는 원본 규칙 그대로 짧은 동사.
- 주 버튼은 오른쪽 끝에 둔다(조건 지우기 → 조회 순서).
