# Nara

나라장터 설계용역 공고를 모아 낙찰업체·진행현황·실행부서를 조사하는 사내 도구의 화면 규칙 — **v2 개선안**. 원본 앱(`jlaw080-ops/Nara-project-renewal`, 커밋 31e4533)의 규칙(v1)은 이 디자인 시스템의 이전 버전에 그대로 남아 있다.

## 무엇을 고쳤나

| 문제 (v1) | 개선 (v2) |
|---|---|
| 메뉴가 오른쪽 위 작은 회색 링크 줄 — 지금 어느 화면인지 안 보임 | 짙은 남색 **앱 바**(AppBar)에 메뉴 탭, 현재 화면에 흰 막대 |
| 모든 버튼이 같은 파란 버튼 — 무엇이 주 동작인지 모름 | **주 · 보조 · 조용한** 버튼 3단계 |
| 진행현황이 그냥 글자 — 표를 훑기 어려움 | 진행현황 **상태 배지**(색 + 글자), 사람이 정한 값은 "수동" 표시 |
| 조회 조건이 화면 절반을 차지, 진행현황은 Ctrl 클릭 다중 select | 두 줄 **조건 패널**: 수요기관은 펼침 메뉴, 진행현황·관심기관은 켜고 끄는 칩 |
| "선택한 사업 숨기기"가 항상 표 위에 있음 | 행을 고를 때만 나오는 **일괄 작업 줄** |
| 표 머리글이 스크롤하면 사라짐 | 머리글 고정, 행 hover, 고른 행 강조 |
| 모든 알림이 같은 모양(.saved) | 저장됨 · 안내 · 주의 · 오류 **네 가지 알림** |
| 흰 바탕에 모든 것이 평평하게 나열 | 회색 바탕(`canvas`) 위 흰 **패널**로 구역 구분 |
| 글자 크기는 브라우저 기본값, 맑은 고딕 | Pretendard, 7단계 글자 크기 |
| 간격 값이 2·4·6·8·12·16px 제각각 | 4px 단위 6단계 |

**그대로 둔 것**: 파란 강조색(#0b57d0), 출력 양식의 짙은 남색 머리글, 표 중심 구성, 화면 문구 규칙, 44px 행 높이, 키보드 포커스 링.

## 성격

Nara는 **표를 읽고 고치는 업무 도구**다. 빠르게 훑고, 정확히 고르고, 바로 내보내는 것이 목적이다.

- 표가 주인공이다. 화면은 앱 바 → 제목·실행 상태 → 알림 → 조건 패널 → 결과 패널(건수·내보내기 → 표) 순서.
- 색은 **뜻이 있을 때만** 쓴다: 파랑(`primary`)은 동작·선택, 상태 색은 진행현황과 알림에만.
- 장식 없음. 패널 그림자는 아주 옅게(`shadow-panel`), 모서리는 살짝(`radius-md` 6px, 패널 `radius-lg` 10px).

## 글쓰기 (화면 문구)

원본 규칙을 그대로 잇는다.

- **버튼은 짧은 동사**: "조회", "저장", "지금 실행", "선택한 사업 숨기기", "이 사업 다시 조회".
- **안내 문장은 존댓말 평서문**: "조건에 맞는 사업이 없습니다", "조건을 좁혀 주세요".
- **알림은 앞머리 2~5글자 제목 + 한 문장**: "저장됨 바꾼 칸: 진행현황", "확인 필요 설치계획 확인이 필요한 사업이 3건 있습니다."
- **보조 설명은 결과를 알려 준다**: 버튼이나 칸 아래 한 줄로 "무엇이 바뀌고 무엇은 그대로인지".
- **빈 값은 "—"**. 나열은 " · ".
- 업무 용어는 원래 이름 그대로: 수요기관, 공고일, 개찰일, 낙찰업체, 실행부서, 신재생 계획, 관심기관.

## 색

| 역할 | 토큰 | 쓰는 곳 |
|---|---|---|
| 바탕 | `canvas` #f6f7f9 | 페이지 바탕 |
| 패널 | `surface` #ffffff | 패널·표·입력칸 |
| 머리글 | `surface-sunken` #f1f3f6 | 표 머리글 |
| 구분선 | `line` #e3e6eb | 패널 테두리, 행 구분 (장식용) |
| 칸 테두리 | `field-line` #7a828e | 입력칸·보조 버튼 테두리 (3.6:1 이상) |
| 글자 | `fg` / `fg-secondary` / `muted` | 본문 / 라벨·머리글 / 도움말 |
| 동작 | `primary` #0b57d0, `primary-hover`, `primary-soft` | 주 버튼, 링크, 선택 |
| 앱 바 | `brand-navy` #1f3864, `on-navy`, `on-navy-muted` | 상단 바, 출력 머리글 |
| 상태 | `success` · `warning` · `danger` (+ 각 `-soft`) | 배지, 알림, 실행 상태 |

규칙:

- 진행현황 색: 착공 전 = 파랑, 시공 중 = 주황, 준공 완료 = 초록, 미확인 = 회색, 판정 전 = 테두리만. **색만으로 구분하지 않는다** — 늘 글자가 같이 있다.
- `danger`는 실패·오류에만. "검토 필요" 같은 할 일은 테두리 배지나 안내 알림으로.
- 모든 글자 조합이 4.5:1 이상 (가장 낮은 것: `muted` on `surface-sunken` 5.1:1). 입력칸 테두리 3.6:1 이상.
- 다크 모드는 아직 없다.

## 글자

- 글꼴 **Pretendard**(400·600·700, SIL OFL 무료 글꼴) — 없으면 맑은 고딕으로 대체.
- `page-title` 22px · `section-title` 17px · `body` 14px · `body-strong` 14px 600 · `label` 13px 600 · `table` 13px · `caption` 12px.
- 표·날짜·금액은 숫자 폭 고정(`tabular-nums`) — 세로로 자릿수가 맞는다.
- 한글 줄바꿈은 낱말 단위(`word-break: keep-all`).

## 배치와 간격

- 4px 단위: `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 24 · `space-6` 32.
- 화면 좌우 여백·패널 사이 `space-5`, 패널 안쪽 `space-4`, 표 칸 `space-2`×`space-3`.
- 내용 최대 폭 `content-max-width` 1440px.
- 표가 넓으면 표 상자만 가로 스크롤, 높으면 머리글이 위에 붙은 채 세로 스크롤.
- 입력칸·버튼 `control-md` 40px, 도구줄 `control-sm` 32px, 표 행 `row-height` 44px.

## 상호작용과 접근성

- 키보드 포커스: `primary` 2px 링 + 2px 여백 (앱 바에서는 흰 링).
- 정렬 머리글은 `aria-sort` + ▲▼, 칩은 `aria-pressed`, 현재 메뉴는 `aria-current="page"`, 고른 행은 `aria-selected`.
- 버튼은 누르면 1px 내려간다(움직임 줄이기 설정이면 그대로).

## 아이콘

아이콘 세트나 로고 파일은 없다. 앱 이름은 글자 "NARA"로 쓴다. 기호는 글자로: ★ 관심기관, ▲▼ 정렬, ▾ 펼침, ↗ 새 탭, ← 목록으로, 상태 점(●)은 CSS로.

## 상세 화면

원본은 일곱 구역(사업 · 공고 · 진행현황 이력 · 실행부서 · 신재생 계획 · 설치계획서 · 수정 이력)을 위에서 아래로 길게 늘어놓아, 핵심 정보를 보려면 끝까지 내려야 했다. 개선안:

- **요약 패널**이 맨 위: 사업명, 수요기관, 진행현황 배지, "이 사업 다시 조회"(보조) · "목록에서 숨기기"(조용한), 그리고 **핵심 숫자 줄**(`.facts`: 공고일 · 개찰일 · 예산 · 낙찰업체 · 실행부서 · 신재생 설치비). 스크롤 없이 사업을 판단한다.
- **구역 탭**(`.tabs`): 각 구역으로 바로 가는 페이지 안 링크, 옆에 건수.
- **두 칸 배치**(`.split`): 왼쪽 넓은 칸에 표가 있는 구역(사업 · 공고 · 진행현황 이력 · 신재생 계획), 오른쪽 좁은 칸에 사람·짧은 기록(실행부서 연락처 · 설치계획서 · 수정 이력 최근 3건). 오른쪽 칸은 스크롤해도 따라온다.
- **사업 정보**는 표 대신 두 줄 정의 목록(`.dl`), 비고는 한 줄 전체.
- **첨부**는 파일 종류가 보이는 단추(`.file`), **신재생 합계**는 표 아래 굵은 합계 줄(`.sum`).
- **연락처**: 부서장·실무 담당자를 사람 카드(`.person`)로, 전화번호는 눌러서 걸 수 있는 링크. 공고문에서 자동으로 읽은 값은 주황 "공고문" 표시(`.auto`).
- **수정 이력**은 "이전 값(취소선) → 새 값(굵게)".
- 사람 판정 잠금은 진행현황 구역 안 안내 알림 + "자동 판정에 다시 맡기기"(보조).

**고치기**: 구역 머리의 "고치기"(조용한 버튼)를 누르면 그 구역 패널이 파란 테두리(`.panel--editing`)의 폼으로 바뀐다. 입력칸은 3열 격자(`.form-grid`), 후보는 근거 문장을 인용한 선택 카드(`.candidate`), 아래 고정 줄(`.form-actions`)에 취소 · **저장**. 저장하면 위에 "저장됨" 알림.

## 설치계획 · 단가 · 설정 화면

공통 규칙 두 가지를 새로 들였다.

- **저장 줄**(`.savebar`): 화면에서 무언가를 고치면 아래에 파란 테두리 줄이 붙어 "무엇을 몇 개 고쳤는지 · 저장하면 무슨 일이 생기는지"를 말하고, 되돌리기(조용한) · **저장**(주)을 준다. 고치기 전에는 보이지 않는다. 단가 관리·설정·설정 확인에서 쓴다.
- **고친 것 표시**: 고친 행은 `warning-soft` 바탕 + 이전 값 취소선(`.was`), 뺄 값은 빨간 취소선 칩(`.value--remove`), 더할 값은 초록 칩(`.value--add`).

화면별:

- **설치계획 목록**: 원본의 "확인 필요 4 · 자동 연결 38 …" 링크 줄을 **묶음 탭**(`.segmented`)으로. 확인 필요 건수는 파란 동그라미로 눈에 띄게. 점수(0.54)는 **일치도 막대**(`.meter`)와 숫자로, 각 행 끝에 "연결하기"(보조).
- **설치계획서 상세**: 오른쪽에 설치계획서 내용, 왼쪽에 **연결할 사업 후보**(`.match`)를 일치도 순으로. 가장 비슷한 후보는 파란 바탕 + 주 버튼, 나머지는 보조 버튼. 후보마다 진행현황 배지·실행부서·신재생 계획을 같이 보여 맞는지 판단을 돕는다. "맞는 사업이 없으면" 아래에 사업 번호로 연결 · 새 사업으로 추가, "무시"는 위 오른쪽 조용한 버튼으로 떨어뜨려 실수로 누르지 않게.
- **단가 관리**: 에너지원별 묶음 행(`.group-row`) 아래 형식마다 표 안 입력칸. 단가가 없는 형식은 빨간 배지 + 위에 주의 알림("합계에서 빠집니다"). 저장 줄이 "사업 128건 설치비가 다시 계산됩니다"를 미리 알린다.
- **설정**: 여섯 종류를 한 화면에 늘어놓던 것을 **왼쪽 메뉴**(`.sidenav`, 개수 표시) + 오른쪽 한 종류로. 값은 체크박스 대신 × 단추가 있는 **값 칩**(`.value`), 더할 값은 한 줄에 하나.
- **설정 변경 확인**: 바뀌는 값을 +/− 칩으로, 영향은 **숫자 카드 세 장**(`.impact`: 걸리는 사업 · 관심에서 빠질 기관 · 다시 수집 필요). 걸리는 사업은 표에서 숨길 것만 고르고, 저장 줄에서 "확인 저장".

미리보기는 `components/bundle.css`(개선안 스타일시트)를 입힌 **정적 시안**이다. 앱은 Jinja 템플릿이라 동작 부품(bundle.js)은 없다.

## 앱에 적용하는 법

Claude Code 개발지시서에 다음을 넣는다.

1. `base.html`의 `<style>`을 이 시스템의 `tokens.css`(색·간격 변수) + `components/bundle.css`로 바꾼다. Pretendard 글꼴 파일(`fonts/`)을 `static/` 폴더에 넣고 `@font-face`로 연결한다.
2. 상단 링크 줄을 AppBar 마크업으로 바꾼다.
3. 템플릿의 `<button>`·`<input>`·`<table>`에 `.btn`, `.input`, `.table` 등 클래스를 붙이고, 진행현황 칸은 StatusBadge로 바꾼다.
4. 사업 조회 화면은 ListScreen 시안 구성을 따른다. 칩 필터와 수요기관 펼침 메뉴, 일괄 작업 줄에는 짧은 JavaScript가 필요하다.
5. 화면별로 하나씩 바꾸고, 기존 테스트(`uv run pytest`)를 돌려 기능이 그대로인지 확인한다.

## 아직 안 한 것

- 로그인 · 비밀번호 바꾸기 화면, PDF 출력 양식.
- 상세 화면의 구역 탭이 스크롤 위치를 따라 바뀌는 동작, 좁은 화면에서 두 칸 → 한 칸 전환.
- 다크 모드, 좁은 화면(휴대폰) 배치.
- PDF 출력 양식은 테두리만 진하게(`print-line`) 바꾸고 나머지는 원본 유지.
